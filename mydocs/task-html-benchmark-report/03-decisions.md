# HTML 벤치마크 보고서 결정 기록

작성: 2026-10-03 · 상태: 구현 진행

- D1. 사용자가 단계별 문서·승인 절차 생략을 승인했다.
- D2. 기존에 검토한 6개 섹션의 심플한 HTML 구성을 사용한다.
- D3. 보고서 전용 LLM 설정을 추가한다. 미지정 값은 Judge 설정을 재사용하되 채점과 서술은 분리한다.
- D4. LLM 실패 시 수치·표 HTML을 생성하고 실패를 표시한다. 기존 벤치마크 상태·종료 코드는 유지한다.
- D5. 사용자가 승인한 구성에 따라 코드가 수치·표를 생성하고 LLM은 구조화된 서술과 근거 ID만 반환한다.
- D6. Tool 수집과 최종 상태 저장 후 HTML을 생성한다. 실패·취소·빈 실행에도 확보한 자료를 사용한다.
- D7. 실행 시 정답·정규화 결과를 보존하고 저장된 실행에서 보고서를 재생성한다.

단계별 승인 문서는 D1에 따라 생략한다. 구현 결과와 검증은 `04-result.md`에 기록한다.
